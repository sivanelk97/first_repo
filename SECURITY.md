# Security Policy

We take security issues in **first_repo Service** seriously.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

1. Use [GitHub private vulnerability reporting](https://github.com/sivanelk97/first_repo/security/advisories/new) for this repository.
2. Include a clear description, steps to reproduce, and any impact you know of.
3. Allow reasonable time for a fix before public disclosure.

We will acknowledge your report and work with you on a resolution.
