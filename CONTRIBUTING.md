# Contributing

Thank you for helping improve this project.

## Opening an issue

1. Search [existing issues](https://github.com/sivanelk97/first_repo/issues) to avoid duplicates.
2. Open a [new issue](https://github.com/sivanelk97/first_repo/issues/new) with a clear title and enough context for others to understand the problem or idea.
3. Include steps to reproduce, expected vs. actual behavior, or screenshots when they help.

## Submitting a pull request

1. Fork the repository and create a branch from `main` with a descriptive name (for example, `fix/typo-in-readme`).
2. Make your changes on that branch and test them locally when applicable.
3. Push your branch and open a pull request against `main` on [GitHub](https://github.com/sivanelk97/first_repo/compare).
4. Fill in the PR description: what changed, why, and how to verify it. Link any related issue (for example, `Fixes #123`).

## Scope of changes

Keep pull requests **small and focused**. Each PR should address one concern—such as a single bug, feature, or documentation update—so reviewers can understand and merge it quickly. If a change would be large, split it into smaller PRs or discuss the approach in an issue first.
